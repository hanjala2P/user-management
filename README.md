# ShopexSmartDeal 🛍️

A full-stack marketplace web app where users can list products for resale, browse listings, and negotiate prices through a bidding system — connecting local buyers and sellers in a smart, simple way.

**🔗 Live Site:** [https://shopexsmartdeals.web.app/](https://shopexsmartdeals.web.app/)

---

## ✨ Features

- 🔐 **Authentication** — Email/password and Google sign-in via Firebase Auth, with a custom JWT layer for securing backend API routes
- 📦 **Product Listings** — Create, browse, and view detailed product listings (title, price range, category, condition, images, seller info)
- 💰 **Bidding System** — Buyers can place bids on any product; sellers can view all bids received for their listings
- 🧾 **My Products** — Sellers can manage (view/delete) their own listed products
- 📊 **My Bids** — Buyers can track and manage (view/delete) the bids they've placed
- 📱 **Responsive Design** — Mobile-friendly layouts across all pages, including card-based views for tables on small screens
- 🔔 **User Feedback** — SweetAlert2 confirmations and notifications throughout (create, delete, login, register, session expiry)

---

## 🛠️ Tech Stack

### Frontend
- **React** (with React Router)
- **Tailwind CSS** + **daisyUI**
- **Firebase Authentication**
- **Axios** (with secured interceptors for protected routes)
- **SweetAlert2** for alerts and confirmations
- Deployed on **Firebase Hosting**

### Backend
- **Node.js** + **Express**
- **MongoDB** (native driver)
- **Firebase Admin SDK** (token verification)
- **JSON Web Token (JWT)** for API authorization
- Deployed on **Vercel** (serverless functions)

## ⚙️ Getting Started

### Prerequisites
- Node.js (v18+)
- A MongoDB database (Atlas or self-hosted)
- A Firebase project (for Authentication + a service account for the backend)

### 1. Clone the repository
```bash
git clone https://github.com/<your-username>/shopexsmartdeal.git
cd shopexsmartdeal
```

### 2. Backend setup
```bash
cd server
npm install
```

Create a `.env` file in the server directory:
```
DB_USER=your_mongodb_username
DB_PASS=your_mongodb_password
JWT_SECRET=your_jwt_secret
FIREBASE_SEVICE_KEY=your_base64_encoded_firebase_service_account_json
```

> `FIREBASE_SEVICE_KEY` is generated by base64-encoding your Firebase service account JSON file (see `encode.js`).

Run the server:
```bash
node index.js
```

### 3. Frontend setup
```bash
cd client
npm install
```

Create a `.env.local` file in the client directory with your Firebase config:
```
VITE_apiKey=...
VITE_authDomain=...
VITE_projectId=...
VITE_storageBucket=...
VITE_messagingSenderId=...
VITE_appId=...
```

Run the client:
```bash
npm run dev
```

## 🔑 Key API Endpoints

| Method | Endpoint | Description |
|---|---|---|
| `POST` | `/users` | Register a new user in the database |
| `GET` | `/products` | Get all products (optionally filter by `email`) |
| `GET` | `/latestProducts` | Get the 6 most recently added products |
| `GET` | `/products/:id` | Get a single product by ID |
| `POST` | `/products` | Create a new product listing |
| `DELETE` | `/products/:id` | Delete a product |
| `GET` | `/bids` | Get bids for the logged-in user (requires JWT) |
| `GET` | `/products/bids/:productId` | Get all bids for a specific product |
| `POST` | `/bids` | Place a new bid |
| `DELETE` | `/bids/:id` | Delete a bid |
| `POST` | `/getToken` | Issue a custom JWT for the logged-in user |
